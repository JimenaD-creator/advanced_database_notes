# Concept name
DBMS_METADATA
## My understanding
DBMS_METADATA is an Oracle tool that helps extract the structure of database objects as SQL code. In simple terms, it lets me see how tables, views, sequences, procedures, or other objects were created by generating their DDL (like CREATE TABLE statements). I see it as a practical way to back up or recreate schema structure when I only have SQL access.

## Why it matters
It matters because it makes schema backup and migration much easier, especially when I do not have access to advanced tools like expdp. Instead of manually rewriting database structures, DBMS_METADATA can generate the code for me. This is useful for moving schemas to another database, documenting structures, or restoring objects after changes or errors.

## Example
```sql
SELECT DBMS_METADATA.GET_DDL('TABLE', 'EMPLOYEES')
FROM dual;
```
This query returns the SQL code used to create the EMPLOYEES table, including columns, data types, and constraints. For example, it may output a CREATE TABLE statement that can be reused in another schema.

# Session – 2026-05-12

## Topics covered
- ORM: Object-Relational Mapping is a tool to interact with relational databases, using the OOP Paradigm of a programming language that converts tables into classes, and rows into objects.
- ORM DB Migration: It acts like a version control of the database schema. Instead of running SQL commands to change tables, we describve our data models in code, and the ORM automatically generates and applies the necessary SQL updates to keep the database in sync.
- Alembic: a migration tool for SQLAlchemy that detects schema changes and generates migration scripts to update the database safely.
- Relationships in ORM:
  - One-to-Many
  - Many-to-One
  - Foreign Keys
  - Cascading deletes

## What I understood
- Alembic works similarly to Git for databases because it tracks schema changes through migration files and allows upgrades or rollbacks between versions.
- ORM helps simplify database interaction because developers can manipulate Python objects instead of writing SQL queries for every operation.
- Relationships make it easier to connect tables logically, such as linking users to teams or tasks to users.
- Migrations help maintain consistency between the application models and the actual database schema across development environments.

# Session – 2026-05-19

## Topics covered
- **Seed dashboard with Plotly + Oracle:** A seed dashboard is an initial version of a dashboard used to visualize business metrics and test KPI ideas. In this practice, Oracle was used as the database source and Plotly was used to create charts and visualizations, such as:
    - Bar charts for tasks per team
    - Pie charts for task status distribution
    - Line charts for task completion trends
    - KPI cards for counts and percentages
- **KPI dashboard design:** A KPI dashboard is a collection of business metrics displayed visually, for example: team velocity, completion rate, on-time delivery rate, overdue task severity. 

## What I understood
- A KPI is not just a query; it needs a clear business definition.
- Metrics should answer a business question, not just return numbers.
- Plotly can be used to visualize KPI results from Oracle queries.
- NULL values and cancelled tasks can significantly affect KPI accuracy.
- Completion rates and efficiency metrics should define exactly which tasks are included or excluded.
- Ordering dashboard results by urgency or workload helps prioritize attention.

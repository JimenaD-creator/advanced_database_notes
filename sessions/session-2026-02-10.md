# Session – 2026-02-10

## Topics Covered
During the session, we reviewed and remembered several fundamental SQL concepts focused on querying databases. The main goal was to understand how to retrieve, filter, and organize data efficiently using basic SQL statements and constraints.

- SELECT QUERIES: Learned to use the SELECT and FROM statements to pull specific columns or entire datasets from the tables.

- QUERIES WITH CONSTRAINTS: Explored the WHERE clause to narrow down results using logical operators, range-based filters like BETWEEN, and set-based filters with IN().

- PATTERN MATCHING: Utilized LIKE and NOT LIKE with wildcards to search for specific text patterns within string data.

- FILTERING AND SORTING: Practiced organizing output using ORDER BY for sorting, DISTINCT for removing duplicates, and LIMIT/OFFSET for handling large volumes of data through pagination.

## What I understood
- How to use the SELECT and FROM statements to display data from a table.

- How to apply the WHERE clause to filter records, using comparison operators such as <>, !=, <=, >=, and range operators like BETWEEN ... AND ... and NOT BETWEEN ... AND ... to create more precise queries.

- How to use DISTINCT to avoid displaying duplicate values in query results.

- How to work with LIKE and NOT LIKE to filter data based on patterns, including case-sensitive searches when applicable.

- How to sort and limit query results using ORDER BY and LIMIT, and how to use OFFSET to define the starting point of the returned rows.
## What is still confusing
- The usage of "OFFSET" to show certain rows.
